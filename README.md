# Lottie Flutter Demo 🤖

Proyecto desarrollado para la exposición sobre animaciones Lottie en Flutter.

## 📱 Descripción

Esta aplicación demuestra la integración de animaciones Lottie en Flutter y el control de su reproducción mediante código.

La aplicación simula visualmente el procesamiento de información mediante IA utilizando una animación Lottie.

> Lottie se utiliza como componente visual para representar el proceso. La animación no realiza procesamiento de inteligencia artificial.

## 🚀 Funcionalidades

- Reproducción de animaciones Lottie.
- Pausar la animación.
- Reiniciar la animación.
- Reproducción en loop.
- Control de velocidad.
- Simulación visual de procesamiento de información.
- Indicador de proceso completado.

## 🛠️ Tecnologías

- Flutter
- Dart
- Paquete `lottie`
- Android
- VS Code
